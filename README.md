## Develop

- DB:       Postgresql with `postgres/postgres` account
- Tools:    mise & task & orbstack for docker
- Lang:     elixir & phoenix

```
# setup
task setup  # maybe need strong network

# getting started
task run    # to run at: http://localhost:4000
task sh     # to enter iex session
```
